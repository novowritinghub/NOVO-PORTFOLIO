## 🚀 Getting Started

### Prerequisites
- Node.js v18+ (tested on Node v24)
- npm or yarn

### Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/<your-username>/novo-writing-hub.git
cd novo-writing-hub
npm install
```

### Local Development Server
Start the development server with hot reload:

```bash
npm run dev
```

### Production Build
Build the optimized production bundle:

```bash
npm run build
```

### Production Preview
Preview the built site locally:

```bash
npm run preview
```
